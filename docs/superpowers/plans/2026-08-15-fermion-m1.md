# フェルミオン対応 M1 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 正方格子・最近接・スピンレスフェルミオン模型を simple update + CTMRG 測定で解けるようにする(swap gate 方式、密テンソル、mptensor 無改造)。

**Architecture:** 脚ごとのパリティ bool ベクトルを持つ薄いラッパー `ftensor<tensor>` と、mptensor と同名の自由関数オーバーロード群(縮約・転置時に Koszul 符号を機械生成)を `src/fermion/` に新設する。既存のテンプレートカーネル(`Simple_update_bond`、CTM 更新、1・2サイト測定)を `ftensor` でインスタンス化し、iTPS ドライバ層の境界で wrap/unwrap する。ボゾン経路はコード・golden とも不変。

**Tech Stack:** C++17 / mptensor(lapack・scalapack 両バックエンド)/ doctest / CMake+ctest / numpy(テスト参照値生成)

**Spec:** `docs/superpowers/specs/2026-08-15-fermion-m1-design.md`(規約・ガード表・API 表はすべて spec が正)

## Global Constraints

- C++17。新規ファイルには既存と同じ GPL v3 ヘッダを付ける(例: `src/tensor.hpp` 冒頭からコピー)

```cpp
#include <vector>
#include <cstddef>
#include <mptensor/tensor.hpp>
namespace tenes { namespace fermion {
using parity_vector = std::vector<bool>;
using leg_parities = std::vector<parity_vector>;

inline parity_vector fuse(const parity_vector& a, const parity_vector& b) {
  parity_vector r(a.size() * b.size());
  for (std::size_t i = 0; i < a.size(); ++i)
    for (std::size_t j = 0; j < b.size(); ++j) r[i * b.size() + j] = a[i] != b[j];
  return r;
}
inline int count_odd(const leg_parities& p, const mptensor::Index& idx) {
  int m = 0;
  for (std::size_t ax = 0; ax < p.size(); ++ax) m += p[ax][idx[ax]] ? 1 : 0;
  return m;
}
inline std::vector<std::size_t> parity_sort_perm(const parity_vector& p) {
  std::vector<std::size_t> perm;
  perm.reserve(p.size());
  for (std::size_t i = 0; i < p.size(); ++i) if (!p[i]) perm.push_back(i);
  for (std::size_t i = 0; i < p.size(); ++i) if (p[i]) perm.push_back(i);
  return perm;
}
}}  // namespace tenes::fermion
```

```cpp
template <class tensor>
void apply_swap(ftensor<tensor>& a, int ax1, int ax2) {
  for (std::size_t n = 0; n < a.t.local_size(); ++n) {
    auto idx = a.t.global_index(n);
    if (a.parity[ax1][idx[ax1]] && a.parity[ax2][idx[ax2]]) {
      typename tensor::value_type v;
      a.t.get_value(idx, v);
      a.t.set_value(idx, -v);
    }
  }
}
template <class tensor>
void apply_parity(ftensor<tensor>& a, int ax) {
  std::vector<double> sign(a.parity[ax].size());
  for (std::size_t i = 0; i < sign.size(); ++i) sign[i] = a.parity[ax][i] ? -1.0 : 1.0;
  a.t.multiply_vector(sign, ax);
}
template <class tensor>
double parity_violation(const ftensor<tensor>& a) {
  double v = 0.0;
  for (std::size_t n = 0; n < a.t.local_size(); ++n) {
    auto idx = a.t.global_index(n);
    if (count_odd(a.parity, idx) % 2 == 1) {
      typename tensor::value_type x;
      a.t.get_value(idx, x);
      v = std::max(v, std::abs(x));
    }
  }
  return v;
}
```

```cpp
static int inversion_sign(const tenes::fermion::leg_parities& p, const mptensor::Index& idx,
                          const mptensor::Axes& axes) {
  int k = 0;
  for (std::size_t x = 0; x < axes.size(); ++x)
    for (std::size_t y = x + 1; y < axes.size(); ++y)
      if (axes[x] > axes[y] && p[axes[y]][idx[axes[y]]] && p[axes[x]][idx[axes[x]]]) ++k;
  return (k % 2 == 0) ? 1 : -1;
}
TEST_CASE("graded transpose applies Koszul signs") {
  tenes::fermion::leg_parities p{{false, true}, {false, true, true}, {false, true}};
  ft a = make_random_ft(mptensor::Shape(2, 3, 2), p, 7);
  mptensor::Axes ax(2, 0, 1);
  ft b = tenes::fermion::transpose(a, ax);
  REQUIRE(b.parity[0] == p[2]);
  for (std::size_t n = 0; n < a.t.local_size(); ++n) {
    auto idx = a.t.global_index(n);
    double va, vb;
    a.t.get_value(idx, va);
    b.t.get_value(mptensor::Index(idx[2], idx[0], idx[1]), vb);
    CHECK(vb == doctest::Approx(inversion_sign(p, idx, ax) * va));
  }
}
TEST_CASE("transpose twice returns original") {
  tenes::fermion::leg_parities p{{false, true}, {true, false}, {false, true}};
  ft a = make_random_ft(mptensor::Shape(2, 2, 2), p, 8);
  ft b = tenes::fermion::transpose(tenes::fermion::transpose(a, mptensor::Axes(1, 2, 0)),
                                   mptensor::Axes(2, 0, 1));
  for (std::size_t n = 0; n < a.t.local_size(); ++n) {
    auto idx = a.t.global_index(n);
    double va, vb;
    a.t.get_value(idx, va);
    b.t.get_value(idx, vb);
    CHECK(vb == doctest::Approx(va));
  }
}
```
